# Security Policy

## Supported Versions

`qbee-connect` is continuously updated with new features, UI improvements, platform compatibility enhancements, and security fixes across supported desktop operating systems (Windows, Linux, and macOS). We do not offer Long-Term Support (LTS) for legacy releases, and only the latest release of `qbee-connect` is actively supported. We strongly recommend always running the latest version.

| Version | Supported |
| ------- | --------- |
| Latest release | :white_check_mark: |
| All older versions | :x: |

## Reporting a Vulnerability

We take the security of `qbee-connect` seriously and appreciate responsible disclosure.

* **Reporting Guidelines:** To report a potential security issue, please review and follow our official [Security Vulnerability Disclosure Policy](https://docs.qbee.io/security-vulnerability-disclosure-policy.html).
* **What to Expect:**
  * **Acknowledgement:** Our team will review your report and acknowledge receipt promptly.
  * **Assessment & Updates:** We will investigate the issue, evaluate its impact, and keep you updated on progress.
  * **Remediation:** If verified, we will issue a security patch in the next release of `qbee-connect`.
* **Coordinated Disclosure:** We ask that you refrain from sharing details publicly until our security team has evaluated and addressed the reported issue.
